# swizzy downloads

Installers for [swizzy](https://swizzy.vercel.app), the AI video studio on a real editor.

Get the latest version from [Releases](https://github.com/swapnilgarg7/swizzy-releases/releases/latest):

- **Mac** (Apple silicon and Intel): `swizzy-macos-universal.dmg`
- **Windows** (64-bit): `swizzy-windows-x64.msi`, or `swizzy-windows-x64-portable.zip` if you can't install

## Opening it the first time

These builds are not signed yet, so your computer will warn you once.

- **Mac:** open the DMG, drag swizzy to Applications and open it. If macOS says it can't verify the app,
  go to **System Settings > Privacy & Security** and click **Open Anyway**.
- **Windows:** if SmartScreen says "Windows protected your PC", click **More info**, then **Run anyway**.
